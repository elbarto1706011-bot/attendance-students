# Паспорт проекта

## Название проекта
Информационная система учёта посещаемости студентов.

## Цель проекта
Автоматизация учёта посещаемости студентов и упрощение работы преподавателей.

## Заинтересованные стороны
- Студенты
- Преподаватели
- Кураторы групп
- Администрация университета

## Основные функции
- Добавление студентов.
- Создание учебных групп.
- Добавление занятий.
- Отметка посещаемости.
- Просмотр истории посещений.
- Формирование отчётов.

## Ограничения
Проект выполняется одним студентом в течение одного семестра.

## Модель разработки
Scrum с короткими итерациями.

## Критерии успеха
Все основные функции должны работать без критических ошибок.
