# Отчёты о посещаемости

## Назначение
Раздел предназначен для просмотра посещаемости студентов.

## Возможности
- Просмотр посещаемости группы.
- Подсчёт пропусков.
- Просмотр посещаемости за определённый период.
- Формирование отчёта.

## Результат
Преподаватель может быстро получить информацию
о посещаемости студентов.
